# No Break Titles 1.2.2 — Joomla 6

Системный плагин заменяет пробелы после настроенных слов и сокращений на неразрывные во всех обычных текстовых узлах страницы сайта: заголовках, статьях, модулях, меню, ссылках, таблицах и других элементах. Поддерживает добавление и изменение текста через AJAX. В административной части не запускается, базу данных не изменяет.

Установите ZIP через «Система → Установка → Расширения» и включите «Система — Неразрывные заголовки» в списке плагинов. Этот пакет обновляет существующий `system/nobreaktitles`, сохраняя его настройки. После обновления очистите кэш Joomla и браузера.

Списки слов и сокращений, а также выбор языка доступны в настройках плагина. Название сохранено для совместимости с версией 1.1.0. Добавлен отдельный список сокращений после числа (по умолчанию р., рр., г., гг.), например `2026 р.`. Единицы измерения можно добавить в этот список.

Плагин не изменяет атрибуты HTML, поля форм, редактируемые области, скрипты, стили, pre/code/kbd/samp, SVG и MathML. Исключить произвольный блок можно атрибутом `data-nobreaktitles="off"`. Обработка выполняется JavaScript в браузере, с учётом соседних текстовых узлов внутри строчных HTML-тегов (span, a, em и др.). Явные переносы br и границы блоков сохраняются. Содержимое iframe и Shadow DOM не обрабатывается.

## Проверка

`node --check media/js/nobreaktitles.js`

`node tests/browser.cjs` — при наличии Playwright и Chromium. Путь к браузеру можно задать через `CHROMIUM_PATH`.

Проверены: заголовки, обычный текст, модули, ссылки, неизменность атрибутов и полей ввода, исключённые блоки, AJAX и изменение существующего текста, повторная обработка. Установка и запуск в самой Joomla 6 в этой среде не проверялись: PHP и Joomla отсутствуют.

## Исправления 1.2.1

- Связывание предлога со следующим словом или числом через строчные теги, например `в <span>Україні</span>` и `з <span>10:00</span>`.
- Связывание чисел с сокращениями года: `2026 р.` → `2026 р.`.
- Observer не реагирует на собственные замены; элементы DOM и их обработчики событий сохраняются.

Если после обновления замены не видны, проверьте включение плагина и его параметра «Включить», режим языка и непустой украинский список слов (в, з, на, до и др.), затем очистите кэш Joomla, браузера и оптимизатора скриптов, если он используется. Если в тексте стоит явный `<br>`, правило не удаляет его.

## Исправления 1.2.2

- Исправлен URL JavaScript: используется абсолютный адрес сайта вместо ошибочного `//media/…`.
- Убраны вызовы getComputedStyle при обработке текста.
- При добавлении блоков обрабатываются новые узлы, без повторного обхода всего родительского контейнера.
